Personal backup workflow

MNQ database backups with Google Drive

MNQ Backup is the OAuth application the MNQ owner uses with rclone to store and retrieve backups of the MNQ SQLite database in the owner’s Google Drive.

The MNQ service can create and verify local SQLite snapshots. When the MNQ host is configured to use Restic for remote backups, Restic encrypts the repository before rclone transfers it to Google Drive. Encryption depends on that server-side configuration; this website does not run backup jobs or handle backup files.

How the workflow is used

Create and verify

The MNQ host creates a SQLite snapshot and checks it before remote transfer.

Store securely

Where Restic is configured, it encrypts backup data on the host before rclone sends it to Drive.

Restore when needed

rclone retrieves the repository data from Drive so the owner can inspect or restore a backup.

Policies

Read the Privacy Policy for details about Google Drive access, local credentials, storage, and revoking authorization. The Terms of Use describe the personal-use scope of this workflow.
