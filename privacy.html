MNQ Backup

Privacy Policy

Last updated: October 27, 2026

Purpose and operator

MNQ Backup is a personal-use Google OAuth application used by the MNQ owner to authorize rclone on the owner-managed MNQ host. It supports storing and retrieving MNQ SQLite database backup data in the owner’s Google Drive. This static website does not run the backup process and does not receive database files.

Google Drive data and use

During authorization, rclone requests the Google Drive scope configured for its remote. The requested scope is shown in Google’s consent flow and determines what Drive files the client can access. rclone uses that access to work with backup repository files, including listing, uploading, downloading, or removing files when the configured backup workflow calls for those actions. The OAuth client is not intended to access Drive data for any other purpose.

Backup transfers occur between rclone on the MNQ host and Google Drive. This website and the GitHub repository do not receive or store the Drive files. Google processes Drive data under Google’s own terms and privacy policies.

Encryption and storage

When the MNQ host is configured to use Restic for remote backups, Restic encrypts repository data on that host before rclone transfers it to Drive. Encryption depends on the host’s Restic configuration and passphrase; this OAuth application and website do not perform encryption or manage the passphrase.

The backup repository is stored in the Google Drive account selected by the owner. Retention and deletion are controlled by the owner’s backup configuration and Drive account. Revoking OAuth access prevents future access through this client but does not delete files already stored in Drive.

Credentials and protection

When rclone is configured on the MNQ host, its configuration contains the OAuth information needed to connect to Google Drive, including authorization tokens. This website never receives or stores those credentials. Their protection depends on access controls and security practices on the host; this website makes no claim that the rclone configuration is encrypted at rest.

Revoking access

The owner can remove MNQ Backup from the Google Account’s third-party connections. The owner can also remove the saved token from rclone’s configuration. Removing authorization does not remove existing backup files from Drive.

Website information

This site is static and has no login, contact form, or analytics code. GitHub Pages hosts the pages and may process standard request information such as visitor IP addresses under the GitHub Privacy Statement.

Policy changes

This policy will be updated if the application’s data practices change.
